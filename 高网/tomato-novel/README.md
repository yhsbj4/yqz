# 番茄风格小说阅读平台（课程设计）

这是一个使用原生 HTML、CSS 和 JavaScript 制作的小说发现与阅读网站原型。视觉上采用橙色品牌强调、书籍封面墙、分类入口、榜单推荐和沉浸式阅读界面；作品名称、简介与章节内容均为本项目原创演示内容。

## 页面

- `index.html`：首页推荐、分类入口、编辑精选与榜单
- `category.html`：作品搜索与题材筛选
- `ranking.html`：人气榜、新书榜与收藏榜
- `detail.html`：作品介绍、书架收藏和章节目录
- `read.html`：章节阅读、字号调整和背景切换
- `bookshelf.html`：本地收藏书架
- `profile.html`：个人阅读偏好设置
- `admin.html`：作品数据管理演示
- `login.html`、`about.html`：登录入口和项目说明

## 本地运行

由于作品数据通过 `fetch` 读取本地 JSON，请在项目目录启动静态 HTTP 服务，而不要直接用 `file://` 打开：

```powershell
python -m http.server 8001
```

然后访问 `http://localhost:8001/index.html`。

## 交互与数据

- 首页和分类页使用 `assets/books.json` 中的本地 mock 数据（10 部作品）。
- 支持作品标题、作者和题材搜索，以及分类筛选。
- 作品收藏保存在浏览器 `localStorage` 中，可在书架页查看。
- 阅读页支持字号调整和阅读背景切换，偏好保存在本地。
- 封面图形由项目自有 CSS 绘制；未加载远程图片、字体或脚本。

## AI 辅助开发说明

本项目在页面结构、样式和交互实现中使用了 AI 辅助。所有示例作品、简介和章节文本为演示用原创内容；上线前应替换为已获授权的作品数据，并为实际素材补充来源及授权记录。
